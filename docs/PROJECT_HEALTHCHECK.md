# Kause 项目体检报告（首轮）

> 体检范围：`backend/app/*.py`、`frontend/src/*.tsx` 的核心链路（会话、集群上下文、修复执行）。

## 总体结论

当前项目已经具备清晰的产品闭环（调查 -> 处方 -> 人审 -> 执行），并且前后端职责基本合理；但在**数据模型一致性**、**会话/资源生命周期管理**和**工程化保障**三方面存在高优先级风险。

---

## P0（必须优先处理）

### 1) 消息模型与读写逻辑不一致（可能导致历史接口运行时错误）

- `Message` 模型中未定义 `cluster_id` 字段。  
- 但在历史接口中直接读取 `m.cluster_id`。  
- 同时，写入消息时也没有显式写入 `cluster_id`。

**影响**
- 历史会话接口存在触发 `AttributeError` 风险。
- 前端「按集群回放上下文」能力会失真。

**建议**
- 为 `Message` 增加 `cluster_id` 外键（或至少可空字段）。
- 所有消息写入点统一写入 `cluster_id`。
- 在读取端兼容老数据（空值兜底）。

---

### 2) MCP 会话的临时 kubeconfig 文件未回收

当前每个集群初始化 MCP 会话时会创建 `NamedTemporaryFile(delete=False)`，但仅在异常分支删除；正常生命周期结束时没有清理该文件。

**影响**
- 长时间运行下临时文件堆积。
- 存在敏感配置落盘残留风险。

**建议**
- 在 `ClusterSessionManager` 中记录临时文件路径。
- `close_all()` 或单集群会话销毁时强制删除。
- 对异常/正常路径统一采用 finally 清理策略。

---

## P1（应在近期迭代处理）

### 3) 单进程内 Session 缓存策略缺少失效与健康探测

`_sessions` 以 `cluster_id` 常驻缓存，缺少：
- 健康检查（MCP 进程是否还活着）。
- 失效重建策略（异常后的自动重连）。
- 集群删除时的主动回收。

**影响**
- 可能出现“缓存命中但底层会话已失效”的隐性故障。

**建议**
- 为 session 增加 last_used / health 状态。
- 每次使用前做轻量探针，失败则重建。
- 删除集群时同步关闭并移除该 cluster session。

---

### 4) 前端 SSE 解析对分块边界不鲁棒

当前按 `chunk.split('\n')` 逐行解析 `data: ...`，若 JSON 被拆分在两个 chunk 间，可能出现解析失败并丢消息。

**影响**
- 流式 UI 偶发丢帧、思考流断裂、状态更新异常。

**建议**
- 引入 `buffer` 累积未完成行。
- 以 `\n\n` 作为 SSE event 边界做完整事件解析。

---

## P2（中期优化）

### 5) 职责分层需要进一步拆分

`backend/app/main.py` 承担了路由、agent 编排、工具执行、数据持久化等多重职责。

**影响**
- 文件过大，测试与维护成本高。
- 改动时易引入回归。

**建议**
- 拆分为：`api/`（路由）、`services/agent.py`、`services/remediation.py`、`services/session_manager.py`。
- 为 LLM/MCP 调用引入接口层（便于 mock 测试）。

---

### 6) 可观测性与错误分类不足

当前以 `print` 为主，缺少结构化日志与请求链路 ID。

**建议**
- 使用 `logging` + JSON formatter。
- 在每次 chat/remediation 请求注入 trace id。
- 区分用户错误、工具错误、系统错误，统一响应结构。

---

## 建议执行顺序（两周）

### Week 1（稳定性）
1. 修复 `Message.cluster_id` 数据一致性问题。  
2. 修复 kubeconfig 临时文件回收。  
3. 增加 session 健康探测与失效重建。  

### Week 2（工程化）
1. 改造前端 SSE 解析器。  
2. 后端主文件按服务分层。  
3. 引入结构化日志与基础回归测试。  

---

## 本轮体检给出的可量化验收标准

- 历史会话接口在“新会话 + 老会话混合数据”下稳定返回。  
- 连续创建/删除集群 100 次后，无残留 kubeconfig 临时文件。  
- MCP 子进程异常退出后，下一次请求可自动重建并恢复。  
- SSE 长文本流式输出不再出现 JSON parse 错误日志。
